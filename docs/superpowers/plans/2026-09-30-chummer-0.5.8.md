# Chummer 0.5.8 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The owner's queued requests: runner-list markers, page-1 print changes, a print background picker, and a "Book style" print sheet modelled on the rulebook's example sheet.

**Architecture:** UI-only changes in the existing React app (`src/ui/Library.tsx`, `src/print/Sheet.tsx` + `sheet.css`, `src/core/ui-kit/settings.tsx`, `src/ui/Background.tsx`), plus a new `src/print/BookSheet.tsx` + `book-sheet.css` chosen by the per-browser print setting. The engine is not changed.

**Tech Stack:** React 19, TypeScript, Vitest, Playwright; fonts from `@fontsource/*` npm packages (bundled — the CSP forbids font CDNs).

**Spec:** the owner's requests, recorded in `.superpowers/sdd/next/backlog.md` (local) and repeated in the Global Constraints below. Reference image for the book style (owner's, local only, never committed or shipped): `.extract/reference/book-sheet-redline.webp`.

## Global Constraints

- Work on branch `feat/0.5.8` from `origin/main` (438f326). Never switch the working tree across commits that untrack the owner's ignored files; never touch `public/data/*.xml`, `public/custom/`, `custom/`, `library/`.
- Runner list: a runner the player made (no `origin` and no `sampleKey`) shows a **"User defined"** chip in place of the Canon/Non-canon marker, medium blue, styled like the existing `NonCanon` chip; a canon example shows nothing new (as today); a non-canon example keeps its Non-canon chip.
- Runner list: a red **"Error"** chip on every overspent runner: a draft whose `price(c, ch).remaining < 0`, or a finalized runner whose `balance(c, ch) < 0`. It has a tooltip/accessible name saying "Overspent by N¥".
- Print (current layout): the Languages / Knowledge section keeps its look and moves onto page 1, directly under Skills. The portrait at the top of page 1 is larger. The "Anarchy 2.0" logo sits on the yellow paint swish, as the app header's brand does (`.brand b` styling).
- Print background picker: when the sheet's background art is on, the player chooses **which** image: "Same as the app" (default) or one of the admin's uploaded images (thumbnails). The choice is remembered per runner in this browser (localStorage key `ca2.sheetArt.<runner id>`, wrapped in try/catch) and shown in the print preview.
- Book style: a third "Printed sheet" option **"Book style"** in Settings (the current two stay; the default is unchanged). One page as the rulebook example: left side light grunge paper with the street name in large brush lettering and the real name beside it; STR AGI WIL LOG CHA EDGE labels in small caps with hand-written numbers and thin rules; Essence; Skills table (Skill, Rating, +Att., = DP, RR as filled red dots), spec rows indented under their skill; Knowledge skills line (languages first); Shadow Amps table (name + type in parentheses, effect lines, Essence, Rating); Weapons & Spells table (name + description, DV, ranges as [OK / OK / Dis. / –], type); Equipment list; Wounds (boxes) + Thresholds (no armor / main armor / mental). Right side: a yellow paint-swish panel (drawn in CSS/SVG) with the round portrait over the runner's backdrop at the top, then Keywords, Dispositions, Cues in a handwriting face, and the Risk Level RR table at the bottom (RR 0–3 × Low/Normal/High/Extreme dice, with the glitch note). Free fonts only via `@fontsource` (a brush display face, e.g. `@fontsource/permanent-marker`; a handwriting face, e.g. `@fontsource/caveat`), no book art, no book fonts. Numbers come from the engine (`derive`, `ampRating`, `ampEssence`), exactly as the current sheet uses them.
- Every new UI string is plain English; accessibility: chips have text, controls have labels.
- Tests: e2e for each visible change (markers, page-1 order, picker remembered per runner, book style renders with the runner's numbers); `npm run check` green; full Playwright run green before release.
