# Phase 1 — NPCs and critters (Chummer 0.7.0, importer module 0.5.0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** GMs and the admin create, edit, import, export and share NPCs and critters; the book's NPCs/critters import; the Foundry module brings them in as sra2 characters.

**Architecture:** An NPC is a `Character` with an `npc` block, stored apart from runners under `charDir/.npcs/<owner>/` and served only by an editor-gated `/api/npcs`; the runner editor runs in an NPC mode; the export format gains optional `npc`/`npcs` fields; the Python importer reads the CRB NPC chapter; the module maps NPCs to sra2 characters.

**Tech Stack:** as the repos already use (TS/React/Vitest/Playwright/Node server/Python unittest; module ES modules/Vitest/Quench).

**Spec:** `docs/superpowers/specs/2026-10-02-npcs-and-compendiums-design.md` (§1, §3, §4).

## Global Constraints

- `Character.npc?: { kind: 'npc' | 'critter' | 'spirit'; tier: 'prime' | 'regular'; fightingSpirit?: 'null' | 'low' | 'high' | 'extreme' }`. XML: `<npc kind="" tier="" fightingSpirit=""/>` as the first child of the character root (schema updated); absent → a runner.
- Critters/spirits may have `identity.metatype = ''`; the UI shows "Critter" / "Spirit"; attribute range checks are skipped for them.
- `averageHits(dp, rr) = Math.round(dp / 3) + rr + 1`; label format `"<Skill> <T> (<rating>+<attr initial>, RR <rr>)"` with the spec name when a spec row.
- Players never get NPCs: store `charDir/.npcs/<owner>/`; `/api/npcs*` requires role editor or admin (403 otherwise); campaign member view never includes NPCs.
- Export format stays version 1; `runners[].npc` and `books[].npcs` are optional.
- Chummer branch `feat/0.7.0` from origin/main; module branch `feat/0.5.0`; the controller merges/releases. Never touch the owner's ignored files (`public/data/*.xml`, `public/custom/`, `custom/`, `library/`); no book text in tests.
