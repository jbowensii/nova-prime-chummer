# SR6 F1 — Chummer SR6 export v1 and the `chummer-sr6-foundry` module Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Chummer's Shadowrun 6 side writes one JSON file format, "Chummer SR6 export v1" (runners, NPCs, books, compendiums), and a new public Foundry module `chummer-sr6-foundry` reads it into a `shadowrun6-eden` 4.x world: runners as Player actors, NPCs/critters/spirits/sprites as NPC/Critter/Spirit/sprite actors, books and GM compendiums as world compendiums per book and topic. Same behaviour as the Anarchy module (Replace / Add as new version / Skip, never an empty pack, never overwrite art the user chose, separate portrait and token, GM-only facts kept from players, Quench tests), and each module refuses the other game's file.

**Architecture:** Two parts. **Chummer (tasks C1–C4, repo `chummer-anarchy2`, branch `feat/sr6`):** a pure producer `src/sr6/engine/export.ts` beside Anarchy's `src/engine/export.ts`, a JSON Schema and a format doc, and the SR6 pages' export buttons (thin, reusing Anarchy's dialog). Every number in the file is Chummer's own (derive, priced, rated, npcValues); the file also keeps each entry's printed values. **Module (tasks M1–M10, new repo `jbowensii/chummer-sr6-foundry`):** the Anarchy module's layout and code patterns, separate code: pure `scripts/lib/` (read, Eden vocabulary, translate, plan, books, icons, ids) unit-tested with Vitest in Node; thin `scripts/foundry/` (apply, books, app, icons, quench) that writes documents. It writes raw inputs only (attribute bases, skill points, mortype, items with their fields) and lets Eden derive pools, monitors, initiative and essence. M10 is a one-line refusal in the Anarchy module.

**Tech Stack:** Chummer: TS/React/Vitest/Playwright, ajv 2020 (already a dev dependency). Module: plain ES2022 modules, no build step, Foundry VTT 13–14 API (ApplicationV2 + HandlebarsApplicationMixin, Actor/Item/JournalEntry/Folder/CompendiumCollection, FilePicker), Vitest + ajv (dev only), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-02-sr6-ruleset-design.md` (§1 "Foundry", §2, §4 NPCs/Compendiums, §5 Export and Foundry module, §6 F1, §7 Safety). Rules for the producer (each is a test below):
- A finalized runner is exported as it stands: `build = currentBuild(ch)` and `karma`/`nuyen` from `balances(ch)`; before Finalize, what's left of the build budgets (`allBudgets(...).karma.left`, `.nuyen.left`). `attributes`, `essence`, `edge` and `derived` come from `deriveSr6(data, cr, view)`; `derived` is left out for an NPC.
- `entryValues(e, rating)`: rating = the given one, else the lowest of `ratingRange(e.attrs.rating)`, else none; `cost`/`avail`/`essence`/`capacity`/`defense`/`threshold`/`drain`(spell `dv`)/`fade`/`karma`/`powerCost`(adept power `cost`) via `rated(attr, rating)` (absent when `n` is null); `legality` via `legality(avail)`; weapon `dv` "3P"/"4S(e)" → `dv` 3/4 and `stun` false/true (`/^\s*(\d+)\s*([PS])/`, else absent); `ar` from `attackRatings(ar).bands` when ok; `modes` = `modes.split(/[\/,\s]+/)` of SS/SA/BF/FA; `ammo` = the leading integer of `ammo`; vehicle `handling`/`accel`/`interval` "a/b" → `[a, b]` (one number → `[a, a]`), the rest `rated`.
- A purchase's `values` = `entryValues(entryOf(x), ratingOf(x, e))` with `cost`, `avail`, `essence` replaced by `priced({ ...x, qty: 1, accessories: [] }, data, cr)` (graded, one unit); a custom line (no id) has `kind` from `x.kind`, `name` `x.name`, empty attrs/parts, `canon: false`. `bonuses` evaluated (× rating when `perRating`, × qty). Accessories recurse.
- Qualities: `positive` from the entry's `kind` attr, `level`, `free`. Picks: `pick` = its PickKind, `kind` the catalog kind of the same name.
- `description` = the entry's `text`, always on a runners file (as Anarchy: the runner's own things; the dialog says so), left out when empty.
- `npc` (an NPC file): `stats: npcValues(npc)`, `pools: npcPools(npc, data)`, `lines`, `kind`, `rating`, `group`, `from`.
- `portrait`/`token` = `identity.portrait`/`identity.token` or null; `ledger` = live entries with Chummer's label text and amounts (void entries left out).

// scripts/lib/read.js
// A Chummer SR6 export file (chummer-anarchy2 docs/sr6-export-format.md): checked before anything in the world changes.
import { FORMAT, OTHER_FORMAT, VERSION } from './constants.js'

const NOT_OURS = 'This file isn’t a Chummer SR6 export.'
const obj = x => x && typeof x === 'object' && !Array.isArray(x)
export function readExport(text) {
  let file
  try { file = JSON.parse(text) } catch { return { ok: false, reason: NOT_OURS } }
  if (obj(file) && file.format === OTHER_FORMAT)
    return { ok: false, reason: 'This is a Chummer Anarchy 2.0 file. Import it with the Chummer Anarchy 2.0 Importer in a Shadowrun Anarchy 2 (sra2) world.' }
  if (!obj(file) || file.format !== FORMAT) return { ok: false, reason: NOT_OURS }
  if (file.version !== VERSION) return { ok: false, reason: `This file is export format version ${file.version}; this module reads version ${VERSION}. Please update this module.` }
  if (file.kind === 'books') {
    if (!Array.isArray(file.books) || !file.books.length) return { ok: false, reason: 'This file has no books in it.' }
    for (const b of file.books)
      if (!obj(b?.source) || typeof b.source.id !== 'string' || typeof b.source.name !== 'string' || !Array.isArray(b.entries))
        return { ok: false, reason: 'This file is damaged: a book is missing its id, name or entries.' }
    return { ok: true, file }
  }
  if (file.kind !== 'runners' || !Array.isArray(file.runners) || !file.runners.length) return { ok: false, reason: 'This file has no runners in it.' }
  for (const r of file.runners)
    if (!obj(r) || typeof r.id !== 'string' || typeof r.streetName !== 'string' || !obj(r.attributes))
      return { ok: false, reason: 'This file is damaged: a runner is missing its id, name or attributes.' }
  return { ok: true, file }
}
